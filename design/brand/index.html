AppHost 图标方案

原来的四宫格标志和 Windows 徽标很像，这里给出三个原创方向，每个方向都演示了小尺寸标志、桌面应用图标，以及顶栏里的实际效果。已选定 A：它直接复用磁贴上的状态环语言；B、C 保留作为记录。源文件为 mark.svg 与 app-icon.svg。

A · 状态环已选定

应用底板外面套一圈状态环，缺口处的圆点表示“活着”。和界面同一套语言：磁贴启动时的扫动环、多服务的分段环，都是这个形状的动态版本。

16px 下仍然能看清缺口和圆点；单色即可成立，不依赖渐变。环上的缺口是和 Instagram 类图标拉开距离的关键，定稿前建议再做一次相似商标检索。

B · 磁贴 H

两块竖磁贴加一块小方块，拼成 Host 的 H，直接呼应磁贴面板。

缺点：H 形标志很常见，辨识度一般；和“运行状态”没有联系。

C · 宿主窗口

一个窗口框里放着一个应用块，右上角的圆点表示在运行。字面意思最直接。

缺点：小尺寸下内部元素挤在一起，容易糊成一团；“圆角框 + 内部图形 + 右上角圆点”的构图和 Instagram 图标很接近。
